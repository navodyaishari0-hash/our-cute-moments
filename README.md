# Our Cute Moments 💗

A tiny, single-file website made with love — a cute bear 🧸 and panda 🐼 hugging while sweet little messages float by. Pure HTML + CSS + JS, no images, no build step.

## ✨ Features
- 10 sweet hand-written moments
- Dreamy animated gradient background + floating hearts
- Heart-burst animation on every tap 💖
- Progress dots & prev/next buttons
- Keyboard (`←` `→` `space`) and swipe support
- Blinking, bobbing, hand-drawn SVG characters
- Fully responsive & respects `prefers-reduced-motion`

## 🚀 Use it
Just open `cute-love-moments.html` in any browser. That's it!

Or serve it locally:

```bash
npx serve .
```

## 💡 Make it yours
Open the file and edit the `moments` list in the `<script>` section to add your own messages — the dots and counter update automatically.
